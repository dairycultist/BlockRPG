# BlockRPG

Open source singleplayer voxel game written in C + OpenGL.

## References

I like the medieval fantasy vibe of Minecraft, so I wanna lean into that. I also like the old console-edition crafting menu (couch gaming omg)

BTA

matcha flavoured (steal copper and bronze and rpg progression and cool food)

stoneblock (steal quest book)

I do like not having infinite worldspace (exploration lowk overrated, base building is where it's at)

I do kinda like the RPG thing where certain gear is restricted to you until you reach a certain level
